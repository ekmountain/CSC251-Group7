# CSC251-Group7
Advanced Java Group Project - Extra Payment

The task is to create a Java application that calculates loans with extra payment.
In the Pearson textbook, loan calculation is covered in chapter 2, chapter 10.
Please don’t add JavaFX, awt, swing, or other technologies in the project.
Input: interest rate, years, loan amount, extra payment
Output: monthly payment and below for each of the 3 conditions:
original interest, current interest, interest saved, total months.
1. If there is No extra payment, output total interest needs to be paid
2. If there is Extra payment for the first month only, output
a. new total interest
b. interest saved compared to original total interest
c. total months needed to pay off the loan
3. If there is Extra payment of $1000 for every month, output
a. new total interest
b. interest saved compared to original total interest
c. total month needed to pay off the loan
